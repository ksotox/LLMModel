# HD scenery set

CC0 1.0 assets from [Poly Haven](https://polyhaven.com) (public domain: free to use, change and share, no credit
required; credited anyway). `manifest.json` lists each asset's Poly Haven id and page.

Fetched by `scripts/fetch-realism-assets.mjs` (run by the "Realism assets" workflow). Used on High and Standard
graphics by `public/js/battle/hdScenery.js`; Basic and a missing set keep the procedural look.
